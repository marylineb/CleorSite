# CLEOR — « Toujours Nous »

Page de campagne pour une collection de bijoux CLEOR, racontée en six chapitres : de « La Promesse » à « Toujours Nous ». Chaque chapitre est associé à un bijou et à un extrait du film de campagne.

> Projet de conception web : ce site n'est pas un site officiel de la marque.

## Stack

HTML · CSS · JavaScript (sans framework)

## Ce que contient la page

- Hero plein écran et navigation qui change au défilement
- Grille des six chapitres, avec compte à rebours vers le prochain chapitre
- Fiches produits ouvertes dans une fenêtre modale
- Lecteur vidéo pour le film de campagne
- Formulaire d'inscription à la newsletter
- Apparition des sections au défilement (`IntersectionObserver`)
- Mise en page adaptée au mobile (media queries)

## Lancer le projet

Aucune installation : ouvrir `index.html` dans un navigateur.

```bash
git clone https://github.com/marylineb/CleorSite.git
cd CleorSite
open index.html
```
